## 概览

**概览** 是 API Router 的默认首页，用于一眼看清全局状态，包括本地服务运行状态、核心指标、提供商健康度以及模型映射摘要。

![概览界面](images/01-overview.png)

### 主要功能

- **服务状态**：显示本地 OpenAI 兼容端点是否已启动、监听地址与端口。
- **核心指标卡**：展示总请求数、成功率、平均延迟、累计 Token 量，点击卡片可跳转监控页。
- **提供商健康**：显示已配置提供商的在线/离线状态、平均延迟、最近一次检查时间。
- **模型映射摘要**：展示已配置的本地模型、所属分组、路由策略及上游目标。
- **快捷操作**：一键检查全部 Provider、打开监控统计、打开请求日志、启动/停止服务。

### 典型操作：启动本地服务

1. 在概览页顶部的服务状态区域，确认当前状态为“服务已停止”。
2. 点击右侧的 **启动服务** 按钮。
3. 等待状态变为 **服务运行中**，此时 `http://127.0.0.1:<端口>/v1` 已可用。
4. 点击端点旁的 **复制** 按钮，可将地址复制到剪贴板，供客户端配置使用。

### 典型操作：刷新提供商健康

1. 在概览页的“提供商健康”卡片右上角，点击刷新图标。
2. 系统将立即对所有已启用提供商执行健康探测。
3. 列表中的状态点与延迟会随之更新。

## 提供商管理

**API 提供商** 页面用于管理上游 LLM 提供商。一个提供商对应一个上游 API 服务，API Router 会把请求转发到这些上游服务。

![提供商列表](images/02-providers.png)

![提供商表单](images/03-provider-form.png)

![提供商卡片详情](images/04-provider-card-detail.png)

### 主要功能

- **提供商列表**：展示所有已配置的提供商，包括名称、Base URL、健康状态、默认模型数量、QPS 限制等。
- **启用/禁用**：通过列表右侧的开关快速控制提供商是否参与路由。
- **健康检查**：对单个提供商或全部提供商执行连通性探测。
- **添加/编辑提供商**：通过表单配置上游服务的连接参数、默认模型、高级选项。

### 典型操作：如何添加提供商

1. 进入 **API 提供商** 页面，点击右上角 **添加提供商** 按钮。
2. 在弹出的表单中选择配置方式：
   - 从 **预设供应商** 下拉框选择常见供应商（将自动填充 Base URL 等）。
   - 或选择 **手动填写**。
3. 填写 **ID**（唯一标识，例如 `openai`）、**显示名称**、**Base URL**。
4. 输入 **API Key**。
5. 点击 **获取模型** 或 **测试连通**，验证 API Key 是否可用。
6. 在 **默认模型** 区域选择或手动添加该提供商支持的模型。
7. 切换到 **高级设置** 标签，可按需调整超时、QPS 限制、并发限制、额外请求头等。
8. 点击 **保存** 完成添加。

### 典型操作：如何编辑或删除提供商

1. 在提供商列表中点击目标提供商卡片，或点击右侧的 **编辑** 按钮。
2. 修改需要调整的字段。
3. 点击 **保存** 应用变更；点击 **删除** 可移除该提供商。

### 典型操作：如何查看提供商卡片详情与启停状态

1. 在提供商列表中点击目标提供商卡片，进入卡片详情视图。
2. 详情页展示该提供商的连接参数、默认模型、健康状态、QPS 限制及最近检查时间。
3. 点击详情页顶部的 **启用/禁用** 开关，可快速控制该提供商是否参与路由。
4. 开关切换后立即生效；禁用后该提供商不再接收新请求。

## 模型路由

**模型映射** 页面用于把客户端使用的本地模型别名路由到一个或多个上游目标。你可以为每个本地模型配置路由策略、Fallback、重试与熔断规则。

![模型路由界面](images/05-routing.png)

### 主要功能

- **本地别名**：客户端请求时使用的模型名称，例如 `gpt-4o`。
- **上游目标**：一个本地别名可对应多个提供商/模型组合，支持设置层级、权重、覆盖参数。
- **路由策略**：支持 **顺序优先**、**按权重**、**轮询** 三种策略。
- **分组管理**：将模型映射分组，便于按业务或团队组织。
- **连通测试**：在创建或编辑映射时测试每个上游目标是否可用。

### 典型操作：如何创建模型映射

1. 进入 **模型映射** 页面，点击右上角 **新建映射** 按钮。
2. 填写 **本地模型名**（客户端将使用该名称调用）。
3. 选择或新建 **分组**。
4. 在 **路由策略** 中选择需要的策略（顺序优先 / 按权重 / 轮询）。
5. 在 **上游目标** 区域点击 **添加上游目标**，依次选择：
   - **提供商**：从已添加的提供商中选择。
   - **上游模型名**：填写或选择该提供商下的实际模型名。
   - **层级**：数字越小优先级越高，用于 Fallback 顺序。
   - **权重**：仅在“按权重”策略下生效。
6. 如需覆盖请求参数，可在对应目标或模型级填写 `override_params` JSON。
7. 在 **重试策略** 中设置最大重试次数，并开启/关闭 **失败切换**。
8. 点击 **连通测试** 验证上游可用性。
9. 确认无误后点击 **创建映射**。

### 典型操作：如何测试模型映射

1. 在模型映射列表中找到目标映射。
2. 点击该映射右下角的 **连通测试** 按钮。
3. 稍等片刻，页面下方将显示每个上游目标的连通状态与延迟。
4. 如果某个目标离线，可点击 **编辑** 检查模型名或 API Key 是否正确。

## 监控

**监控统计** 页面聚合所有转发请求的运行指标，帮助你追踪用量、费用、延迟与错误趋势。

![监控界面](images/06-monitoring.png)

### 主要功能

- **时间范围切换**：支持查看 **今日 / 本周 / 本月** 的聚合数据。
- **提供商筛选**：可只查看某个提供商的统计。
- **核心指标**：总请求数、Token 总量、平均延迟、错误率。
- **请求量趋势图**：按时间展示请求量走势。
- **Token 用量分布**：通过环形图展示各提供商的 Token 占比。
- **延迟分布**：展示 P50 / P95 / P99 延迟以及各延迟区间的占比。
- **聚合统计表**：按提供商和上游模型汇总请求数、成功/失败、成功率、平均延迟、重试、Token 等。
- **异常洞察**：展示失败率最高、延迟最高、限流最多的模型，点击可跳转日志。

### 典型操作：如何查看某段时间的用量

1. 进入 **监控统计** 页面。
2. 在右上角选择时间范围：**今日 / 本周 / 本月**。
3. 如需只看某个提供商，可在右侧下拉框中选择对应提供商。
4. 观察顶部指标卡、趋势图与 Token 分布图的变化。

### 典型操作：如何导出统计

1. 在监控统计页面右上角点击 **导出 CSV**。
2. 系统将当前聚合数据导出为 CSV 文件。
3. 使用表格软件打开即可进一步分析。

## 日志

**请求日志** 页面记录并展示每一次转发的详细情况，便于排查问题、审计调用。

![日志界面](images/07-logs.png)

### 主要功能

- **日志列表**：展示时间、请求 ID、本地模型、提供商、上游模型、端点、状态、耗时、重试、降级、Token、错误等信息。
- **状态筛选**：支持全部 / 成功 / 错误 / 4xx / 5xx 快速筛选。
- **多维度过滤**：按模型、状态、流式/非流式、时间范围筛选。
- **请求详情**：点击任意一行可查看该请求的完整信息，包括错误信息、请求体、响应体。
- **复制 cURL**：在详情面板可复制等价的 cURL 命令。
- **导出与清空**：支持导出日志和清空本地日志记录。

### 典型操作：如何查看失败请求详情

1. 进入 **请求日志** 页面。
2. 点击顶部状态筛选按钮中的 **错误**，或在状态下拉框中选择 **失败 / 5xx**。
3. 在列表中点击目标请求行。
4. 页面下方展开的 **请求详情** 面板会显示错误信息、请求体和响应体。

### 典型操作：如何启用详细日志

1. 如果日志页面顶部出现提示“请求日志记录未启用”，点击 **前往设置**。
2. 在 **设置 > 日志** 区域开启 **启用详细日志**。
3. 按需选择 **日志级别** 和 **日志保留** 天数。
4. 点击右上角 **保存设置**。
5. 返回日志页，后续请求将记录完整请求体与响应体。

## 设置

**设置** 页面用于配置本地服务的运行参数、路由默认行为、缓存、熔断器、健康检查、日志等全局选项。

![设置界面](images/08-settings.png)

### 主要功能

- **服务**：配置监听端口、绑定地址、本地 Token 鉴权、CORS。
- **路由默认**：设置新建映射时的默认重试次数、超时、自动 Fallback、默认流式传输。
- **缓存**：开启响应缓存，选择 simple / TTL / LRU 模式，配置 TTL 与最大条目数。
- **熔断器全局默认**：配置连续失败阈值、失败率阈值、冷却时长、触发熔断的状态码。
- **健康检查**：开启/关闭自动健康检查并设置检查间隔。
- **日志**：配置日志级别、日志保留天数、是否启用详细日志。
- **关于**：查看版本、架构信息、检查更新、查看源码。

### 典型操作：如何修改服务端口

1. 进入 **设置** 页面。
2. 在 **服务** 卡片中找到 **监听端口** 输入框。
3. 修改为想要的端口号（例如 `6123`）。
4. 点击右上角 **保存设置**。
5. 返回 **概览** 页面，重启服务使新端口生效。

### 典型操作：如何开启本地 Token 鉴权

1. 在 **设置 > 服务** 区域，打开 **本地 Token 鉴权** 开关。
2. 在下方出现的 **API Token** 输入框中填写 Token（例如 `sk-...`）。
3. 点击右上角 **保存设置**。
4. 此后调用本地端点时需要在请求头中携带 `Authorization: Bearer <token>`。
