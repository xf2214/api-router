# 大模型 API 统一路由客户端 —— 产品需求文档（PRD）

## 1. 产品定位
一款**本地运行**的轻量级桌面软件，把多个大模型厂商（OpenAI、Claude、Gemini、Azure、DeepSeek、阿里云等）的订阅 API 统一封装成本地标准 API。用户只需配置一次，即可通过单一本地端点调用不同模型，降低多密钥、多格式、多计费的管理成本。

## 2. 目标用户
- 开发者 / AI 应用团队：需要同时接入多个模型做 A/B 测试或 fallback。
- 个人高级用户：拥有多个平台 API Key，希望统一调用入口。
- 对数据隐私敏感的用户：请求在本地转发，不经过第三方聚合服务。

## 3. 核心目标
| 目标 | 说明 |
|------|------|
| 绝对轻量 | 安装包 < 30 MB，运行时内存 < 150 MB，启动 < 2 秒。 |
| 极高可靠性 | 本地服务 7×24 常驻，支持自动重连、失败转移、配置热重载。 |
| 双客户端 | 同时支持 Windows 10/11 与 macOS 12+（Intel / Apple Silicon）。 |
| 统一接口 | 对外暴露 OpenAI 兼容的 `/v1/chat/completions` 等端点。 |

## 4. 功能需求

### 4.1 提供商管理
- 支持新增、编辑、删除、启用/禁用 API 提供商。
- 每个提供商包含：名称、Base URL、API Key、默认模型列表、自定义 Header、超时时间、QPS/并发限制。
- 支持 OpenAI 兼容格式与自定义格式模板（可选）。

### 4.2 模型路由
- 将远程模型别名映射到本地模型名，例如 `gpt-4o` -> OpenAI，`claude-3-5-sonnet` -> Anthropic。
- 支持同一名称指向多个后端，实现按权重或顺序的负载均衡。
- 支持 Fallback：主后端失败时自动切换备用后端，并可配置重试次数。

### 4.3 本地 API 服务
- 默认监听 `127.0.0.1:6123`，可修改端口。
- 提供与 OpenAI 兼容的 REST API：`/v1/models`、`/v1/chat/completions`、`/v1/embeddings`、`/v1/completions`。
- 支持流式（SSE）与非流式响应透传。

### 4.4 安全与隐私
- API Key 使用系统钥匙串/Windows Credential 加密存储，不在配置文件中明文保存。
- 支持本地访问白名单 / API Key（可选）。
- 所有请求日志仅保存在本地，不上传云端。

### 4.5 监控与统计
- 实时显示当前服务状态、已配置模型数、当日请求数。
- 记录每次请求的模型、后端、延迟、Token 用量（若返回）、状态码。
- 支持按天 / 周 / 月查看用量与费用估算。

### 4.6 配置与升级
- 配置文件为本地 JSON/YAML，支持导入/导出与备份。
- 支持一键检查更新与离线安装包下载。

## 5. 非功能需求
- **性能**：单并发请求 P99 转发延迟 < 50 ms（不含远程模型耗时）。
- **稳定性**：连续运行 30 天不崩溃；异常后端 3 次失败后自动隔离。
- **可维护性**：核心代码 Rust，前端纯 Web 技术，便于长期维护。
- **可扩展性**：预留插件接口，未来可接入新的鉴权或响应转换器。

## 6. 成功指标
- 安装后 5 分钟内完成首个模型配置并调用成功。
- 软件崩溃率 < 0.1%（按运行时长计）。
- 启动到本地服务可用 < 2 秒。

## 7. 风险与应对
| 风险 | 应对 |
|------|------|
| 各厂商 API 格式差异 | 核心只支持 OpenAI 兼容格式；其他格式通过可配置转换模板处理。 |
| 密钥安全 | 使用操作系统原生凭据管理，配置文件仅保存加密句柄。 |
| 跨平台打包复杂 | 采用 Tauri v2 统一构建，GitHub Actions 自动化签名与发布。 |
